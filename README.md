# Sartaj AI Creator Portfolio

A clean and beginner-friendly personal portfolio website for **Sartaj**, an AI Creator from India 🇮🇳.

## About

This website introduces Sartaj and highlights his interest in AI video creation, AI image generation, prompt writing, storytelling, YouTube content, and learning through AI experiments.

## Website Sections

- Hero
- About Me
- Skills
- Projects
- AI Tools
- Contact

## Built With

- HTML
- CSS
- Basic JavaScript

## Project Files

- `index.html` - The main website page.
- `style.css` - The design, colors, layout, and mobile styles.
- `script.js` - A small script for the mobile navigation menu.
- `README.md` - This project explanation.

## Notes for Beginners

You can open `index.html` in a web browser to view the website. The contact links are placeholders and can be replaced with real links later.
